# Project Ideas and JavaScript Practice

This repository contains my assignment for project ideas and JavaScript practice.

## Files

- `IDEAS.md` contains five project ideas, the one I would choose, a two-week plan, and who I could ask for feedback.
- `solutions.js` contains answers to the eight JavaScript questions and test examples.

## How to run

Install Node.js, open a terminal in this folder, and run:

```bash
node solutions.js
```

The file uses Node.js's built-in `assert` module, so no extra packages are needed. If the tests pass, it prints `All tests passed.`
